# 🤖 Local AI Agent

Локальный AI-агент, работающий через OpenAI GPT-4o-mini и LangGraph, который может управлять вашей системой, искать информацию в интернете и использовать специализированные инструменты.

## 🌟 Возможности

Агент умеет выполнять следующие задачи:
- **Поиск в сети:** Актуальная информация через DuckDuckGo.
- **Погода:** Получение текущей температуры и ветра в любом городе мира.
- **Криптовалюты:** Актуальные курсы монет через CoinGecko API.
- **Файловая система:** Чтение и создание локальных файлов.
- **Терминал:** Выполнение системных команд (с фильтрацией опасных операций).
- **QR-коды:** Генерация QR-изображений из текста или ссылок.
- **Напоминания:** Локальный менеджер задач и расписания.
- **Память:** Сохранение истории диалога в `data/memory.json` для сохранения контекста.

## 🛠 Технологический стек

- **Язык:** Python 3.12
- **LLM:** `gpt-4o-mini` (OpenAI)
- **Фреймворк:** `LangGraph` (StateGraph / React Agent)
- **Библиотеки:** `requests`, `duckduckgo-search`, `qrcode`, `python-dotenv`

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка API ключа
Создайте файл `.env` в корне проекта (используя `.env.example` как шаблон) и добавьте ваши ключи:
```env
OPENAI_API_KEY=sk-your-openai-api-key-here
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1
```

### 3. Запуск
```bash
python -m agent.run
```

## 📁 Структура проекта

- `agent/`: Основной исходный код проекта.
    - `agent.py`: Логика инициализации LLM (LangGraph) и управления памятью.
    - `tools.py`: Определение всех функций (инструментов), доступных агенту.
    - `run.py`: Точка входа, реализующая CLI-интерфейс.
    - `bot.py`: Интеграция с Telegram.
- `data/`: Папка для хранения пользовательских данных и артефактов.
    - `memory.json`: Хранилище истории общения.
    - `qr_code.png`: Результаты генерации QR-кодов.
- `.env`: Конфигурационный файл с секретами (игнорируется git).
- `requirements.txt`: Список необходимых зависимостей.
